# Statistical analysis code for PCCM-D-26-00268

This package contains the R analysis scripts and aggregate outputs for the accompanying manuscript and its
Supplemental Digital Content.

## Data and execution

Run scripts from the package directory in the order specified in `execution_order.txt`.
Full execution requires the authorized individual-level input `data/delirium_op.csv`.
Script 01 creates `output/phase1_reconstructed_data.rds` and `.csv` (individual-level intermediate data), which must
remain in the authorized analysis environment. Fitted-model RDS objects generated by script 07 also remain in that environment and are not part of the public distribution.
Individual-level input and intermediate data are not distributed because of ethical and privacy restrictions.
The package alone therefore does not permit independent execution from participant records.

R session information is in `sessionInfo.txt`; installed package versions are listed in `package_versions.csv`. Script 42 additionally requires `magick` for image composition.
The script-to-output mapping is in `script_output_map.csv`. Script numbers need not match Supplementary Table numbers.

## Random number generation

Bootstrap procedures use `set.seed(20260818)` in scripts 07, 18, 24, 29, and 30. Script 30 assigns fixed resampling stream positions to each biomarker/timepoint/model combination, as specified in the code.
Figure 2 Panel A (script 41) spreads its points horizontally with jitter, for display only. The jitter is seeded
(`seed = 20260818`, passed to `position_jitterdodge`), so the panel is identical from run to run; no reported
statistic depends on it.

## Analytical definitions

Biomarker phenotypes are assigned independently at D1 and D5 from the morning CAPD/RASS assessment.
CAPD >=9 with RASS >=-3 defines delirium; RASS -4/-5 defines coma and makes CAPD nonevaluable.
Cox mortality models use D1 CRP and TNF-alpha concentrations and overall follow-up and are fitted as crude and PRISM IV-adjusted models. Mortality counts by neurological phenotype are descriptive, without between-group hypothesis testing.
Baseline characteristics are grouped by D1 phenotype. Acute kidney injury is KDIGO stage >=1.
GSH concentrations are in micromol/mL; NfL and S100B concentrations are in ng/mL.
The ROC metrics corresponding to Supplementary Table 12 are in `output/TABELA14_COMPLETA_com_todos_ICs.csv`.

## Outputs and confidentiality

The supplied outputs contain aggregate results only. Apart from the intermediate data created by script 01, the scripts
do not print or write participant identifiers; identifier fields of the influence diagnostics are written as "withheld".
No individual-level data are included in this software package.

## Additional calculations

Script 44 generates baseline summaries and group tests for Supplementary Table 3, using type-6 quartiles,
Kruskal-Wallis tests, and Fisher exact tests.
SHA-256 checksums are listed in `SHA256_manifest.txt`.

## Required dependency preflight and degrees of freedom

Run `00_check_dependencies.R` first. The required packages are cowplot, emmeans, ggplot2, influence.ME, lme4, lmerTest, magick, pROC, performance, survival, and pbkrtest. Install missing packages before execution. Scripts using emmeans explicitly request Kenward-Roger degrees of freedom and stop if pbkrtest is missing; a silent Satterthwaite fallback is not permitted. The installed package versions used for verification are in package_versions.csv.

## AUC inference

Script 46 produces output/TABLE14_AUC_WALD_P.csv for the eight biomarker-by-day AUCs in Supplementary Table 12. Two-sided Wald tests of H0: AUC=0.5 use DeLong variance. Exact p values and formatted values are retained. Values below 0.001 are displayed as p < 0.001; other p values are displayed to three decimal places. These exploratory tests and bootstrap percentile confidence intervals do not correct for biomarker-selection optimism or provide external validation. Bootstrap intervals quantify sampling uncertainty.

Biomarker selection uses the multi-domain screening results from D1, D5 and temporal change; the retained Cox models focus on the initial D1 assessment. Selection was not based solely on D1 evidence.

## ROC selection and sensitivity models

The reported sensitivity analyses use the full cohort. Figure 2 Panel B contains six model specifications per biomarker. Script 33 reproduces the original four-component ROC selection score using phenotype main-effect tests only; interaction tests do not contribute. It retains the subgroup computations solely to reproduce the selection record, and does not produce separate subgroup result tables. This original score is not recalculated with a reduced denominator. The ROC panel consists of NfL, S100B and IL-6; selection and evaluation used the same cohort.

## Public release contents

This repository distributes analysis code and the aggregate CSV outputs listed in the SHA-256 manifest. The data directory, participant-level intermediate files, fitted-model objects, execution logs, and diagnostic graphics generated during execution are not public release artifacts. The .gitignore file excludes these generated files and permits only the listed aggregate CSV outputs under output/.
